# 파일럿: Claude(PM·QA) + OpenCode(개발, Meta Muse 모델)

목표: 같은 SPEC을 "Claude 단독"과 "Claude + OpenCode/Muse"로 구현해 비용·시간·품질을 비교한다. 개발 단계는 **무료 경로**로 진행한다.

| 단계 | 담당 | 산출물 |
|---|---|---|
| 1. 기획·구조 | Claude Code | `pilot/SPEC-NNN-*.md` |
| 2. 개발 | OpenCode (Muse 모델) | 코드 변경 + 스펙 10절 완료 보고서 |
| 3. 검증 | Claude Code | `pilot/QA-NNN.md` |

## 공통 규칙
- 개발 에이전트는 **SPEC 5절의 파일 목록만** 수정한다. 모호하면 11절에 질문을 적고 멈춘다.
- QA는 개발 에이전트의 보고를 믿지 않고 **직접 재실행**한 결과로 판정한다.
- 같은 SPEC이 QA에서 **2회 연속 반려**되면 Claude가 직접 구현한다.
- 작업마다 QA 문서 8절(파일럿 측정)을 기록한다.

## 무료 경로 (개발 단계)
> 아래 무료 조건은 제3자 자료 기준이며 **한시적**이다. 시작 전에 공식 문서에서 현재 조건을 확인한다.
> - OpenCode Zen: https://opencode.ai/docs/zen/
> - Meta Model API / Muse Code 약관·가격 페이지

### 사용 순서
1. OpenCode를 설치한다.
2. `/connect` → **OpenCode Zen**을 선택하고 가입 후 API 키를 붙여 넣는다 (카드 불필요로 알려져 있음, 확인 필요).
3. 모델 목록에서 `Muse Spark 1.3 Contributor Free`(또는 현재 목록의 무료 Muse 모델)를 선택한다.
4. 대안: Muse Code(베타 무료, 일일 토큰 한도), 또는 Meta Model API 가입 시 1회 제공되는 크레딧(약 $20, 확인 필요).
5. 구현 지시는 `pilot/SPEC-NNN-*.md` 파일 하나만 가리킨다. 예: "`pilot/SPEC-001-weather-timeout.md`를 읽고 그대로 구현해. 5절 파일 외에는 수정하지 마."

### 데이터 규칙 (필수)
- 무료 모델의 "Contributor"는 **Meta가 입력 코드를 학습에 사용하는 것을 허용하는 티어**일 가능성이 높다. 사용 전에 약관에서 직접 확인한다.
- **허용**: 공개해도 무방한 코드.
- **금지**: API 키, 토큰, `.env`, 개인정보, 고객 데이터, 비공개 로직. 이런 파일은 에이전트가 읽지 못하게 하고 프롬프트에도 붙여 넣지 않는다.
- 이 저장소의 `.env.example`은 샘플만 있어야 하고 실제 키는 커밋하지 않는다.

### 한도와 중단 처리
- 무료 모델은 일일·분당 한도로 중간에 끊길 수 있다. 끊긴 시각과 사유를 QA 8절 "비고"에 적고, 소요 시간에서 대기 시간을 분리해 기록한다.
- 모델이 무료 목록에서 사라지면 같은 SPEC으로 다른 무료 모델(목록의 다른 계열)을 선택해 다시 측정한다. 모델이 달라졌다는 사실을 측정표에 기록한다.
- 유료 키나 크레딧을 연결할 때는 반드시 **월 사용 한도**를 설정한다.

## 비교 설계
| 방식 | 구성 | 비용 |
|---|---|---|
| A | Claude 단독 (기준선) | 기존 구독 |
| B | Claude(PM·QA) + OpenCode + 무료 Muse | 무료(한도 내) |
| C (선택, B 안정화 후) | B + OMO(Oh My OpenCode) | 무료(한도 내) |

- C는 OMO가 지정한 Muse 모델을 **실제로 호출하는지** 확인한 뒤에만 진행한다. OMO 기본 제공자 목록에 Meta가 없고, 사용자 지정 모델이 무시되고 기본 fallback으로 대체되는 버그가 보고된 적이 있다(oh-my-openagent 이슈 #3040, 최신 상태 확인 필요). OpenCode 로그와 제공자 대시보드에서 호출 모델을 확인한다.
- 같은 종류의 작업 5~10개를 방식별로 수행하고, 작업 순서에 따른 편향을 줄이기 위해 방식 실행 순서를 섞는다.
- 판단 기준: QA 반려 횟수, 사람 개입 횟수, 총 소요 시간(대기 제외), 만족도. 무료 경로의 목표는 "A 대비 B의 품질이 허용 가능한가"이다.

## 계정 안전
- **Claude 구독(Pro/Max)을 OpenCode에 연결하지 않는다.** 서드파티 도구에서의 구독 사용은 약관상 제한되며 계정 정지 사례가 보고됐다(최신 약관 직접 확인).
- Claude는 공식 도구인 Claude Code에서만 PM·QA로 쓴다.
