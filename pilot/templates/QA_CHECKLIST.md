- 대상 SPEC: SPEC-001
- 검증 대상 커밋/브랜치:

## 3. 범위 검증
- [ ] 변경 파일이 SPEC 5절 목록 안에 있다 (`git diff --stat`으로 확인)
- [ ] Non-goals를 건드리지 않았다
- [ ] 불필요한 주석, 포맷 변경, 리팩터링이 없다
- [ ] 의존성이 SPEC 없이 추가되지 않았다
- [ ] 병렬 태스크 간 충돌·중복 구현이 없다

## 4. 코드 리뷰
- [ ] 로직 오류, 경계값, null/빈 입력 처리
- [ ] 에러 처리 (삼키는 예외, 누락된 실패 경로)
- [ ] 기존 코드 패턴·네이밍과 일치
- [ ] 중복 코드, 죽은 코드
- [ ] 테스트가 실제로 동작을 검증한다 (항상 통과하는 테스트 아님)

## 5. 보안 / 비밀 정보
- [ ] API 키·토큰·개인정보가 코드, 로그, 커밋에 없다
- [ ] 사용자 입력 검증/이스케이프
- [ ] 새 외부 호출·권한이 SPEC에 명시돼 있다
